# GDevelop Gameplay Tests
Consultar ejemplos/documentación oficial. No inventar APIs del harness. Cada test debe tener comportamiento observable, setup mínimo y determinista. Screenshots complementan assertions. No ocultar fallos. Guardar resultados y evidencia. No sustituir pruebas de dispositivo cuando el requisito sea táctil/layout real.
