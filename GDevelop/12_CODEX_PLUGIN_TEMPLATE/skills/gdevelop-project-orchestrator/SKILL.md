# GDevelop Project Orchestrator
1. Leer AGENTS, GAME_SPEC, PROJECT_STATE y TASK_SPEC.
2. Explorar en modo lectura.
3. Buscar fuente oficial o ejemplo mínimo.
4. Cargar gdevelop-reference si se edita JSON interno.
5. Planificar pasos pequeños.
6. Implementar solo alcance autorizado.
7. Generar preview si es posible.
8. Ejecutar gameplay tests.
9. Aplicar gate visual si corresponde.
10. Revisar diff y actualizar continuidad.
Nunca inventar identificadores ni declarar PASS sin evidencia.
