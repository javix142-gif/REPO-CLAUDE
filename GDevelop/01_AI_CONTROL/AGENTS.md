# AGENTS.md — GDevelop + IA

## Objetivo
Desarrollar juegos GDevelop con cambios pequeños, auditables y verificables.

## Leer antes de modificar
1. `GAME_SPEC.md`
2. `PROJECT_STATE.md`
3. `TASK_SPEC.md`
4. contratos visual/assets si aplican
5. fuentes oficiales concretas
6. skills relevantes

## Reglas
1. Explorar antes de modificar.
2. No inventar acciones, condiciones, expresiones, behaviors ni campos JSON.
3. Buscar ejemplo oficial o referencia verificada cuando falte contrato.
4. No editar fuera del alcance.
5. No hacer refactor global en una corrección puntual.
6. Mantener editabilidad desde GDevelop.
7. Preferir eventos/behaviors nativos antes que JS ad-hoc.
8. No instalar dependencias sin justificar.
9. No tocar secretos.
10. No ejecutar comandos destructivos.
11. Terminar con preview/pruebas/diff según corresponda.
12. No declarar PASS visual sin captura real.
13. No declarar PASS funcional sin prueba suficiente.
14. En móvil, validar táctil, safe areas, ratio, orientación y rendimiento.
15. Reportar evidencia faltante; no simular éxito.

## Cierre
Resumen; archivos; pruebas; evidencia; riesgos; pendientes; siguiente paso.
