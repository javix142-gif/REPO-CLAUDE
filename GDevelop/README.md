# GDEVELOP AI MASTER KIT

Kit maestro para desarrollar juegos GDevelop con agentes de IA de forma controlada, verificable y reproducible.

## Contiene

- reglas persistentes para agentes;
- skills de GDevelop;
- integración MCP;
- repositorios oficiales de documentación, ejemplos, extensiones y tutoriales mediante lock reproducible;
- contratos de assets y visuales;
- gameplay tests y gates;
- plantilla de proyecto;
- scripts de instalación, actualización, búsqueda y verificación;
- catálogo de fuentes comunitarias y opcionales.

## Inicio

1. Leer `00_START_HERE/00_LEEME_PRIMERO.md`.
2. Ejecutar `08_SCRIPTS/01_FETCH_ALL_REFERENCES.ps1` para materializar los repositorios fijados.
3. Si se usará MCP, revisar `03_MCP/SECURITY_REVIEW.md` y ejecutar explícitamente `02_INSTALL_MCP_DEPENDENCIES.ps1 -IUnderstand`.
4. Crear proyectos con `07_NEW_PROJECT.ps1`.
5. Mantener `AGENTS.md`, `PROJECT_STATE.md`, `GAME_SPEC.md` y gates dentro del proyecto.

No se incluyen contenidos premium ni assets con licencias dudosas.
