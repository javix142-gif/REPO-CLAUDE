## Umbral de Ceniza — RPG de acción 2D para Android (GDevelop)

Juego completo al estilo *Darkrise*: 3 clases, pueblo con herrería/alquimista, 10 etapas de mazmorra con oleadas y
jefe, botín por rareza, niveles, controles táctiles y combate automático. Arte y audio originales.
